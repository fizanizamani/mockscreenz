# Signly (mockscreenz) — Pakistan Sign Language & Smart Assistive System

Interactive UI prototypes, mock screens, and design assets for the **Signly / IsharaX** Pakistan Sign Language (PSL) & Smart Assistive System.

## Overview
- **Interactive Prototype**: [`index.html`](./index.html) — High-fidelity interactive prototype featuring live camera translation, bilingual chat, emergency alerts, educational modules, and voice synthesis.
- **Brand & Media Assets**: [`assets/`](./assets/) — High-resolution avatars, logos, and UI illustration assets.
- **Project Proposal & SRS**: [`IsharaX_Proposal_SRS_Complete_Project_Document.docx`](./IsharaX_Proposal_SRS_Complete_Project_Document.docx) — Complete specification document.

## How to View
Open `index.html` in any modern web browser or run a local static web server.
